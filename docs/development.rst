===========
Development
===========

For development inside TorchLBM, but also for simply running simulations, we recommend using the code editor `Visual Studio Code`_. It is available open source for several platforms (Linux, MacOS, Windows). Also, it allows installing several extensions easing the development process. To develop inside TorchLBM, we recommend the following extensions:

* Python_: Simplifies writing Python code.
* autoDocstring_: Automates generating docstrings to comment the code. Docstring comments are required for the documentation using Sphinx.
* `Remote - SSH`_: Simplifies development on remote machines.
* `Live Preview`_: Allows to preview several document types inside the VSCode window. This is especially useful for previewing the HTML documentation during remote development.
